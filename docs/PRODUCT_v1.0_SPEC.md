# PrismOS 1.0 製品版仕様書 — Windows 11 レベル

> **製品版の定義:** PrismOS 1.0 は、日常の PC として Windows 11 と同じレベルのことが
> できる、完成した OS である。起動して、ネットにつなぎ、ファイルを扱い、アプリを
> 入れて、仕事・勉強・遊びができる。初心者でも使えて、どこでもカスタムできて、
> セキュリティも最初からしっかりしている。
>
> **バージョンの整理:** 開発版は v0.1 → v0.9 と進み、v1.0 到達をもって製品版とする。
> ユーザーの「v10.0にて、製品版v1.0とする」は、この到達点を製品版 v1.0 と呼ぶ
> ものとして受け取った。もし番号の付け方を v10.0 にしたい場合は、ここだけ
> 読み替えればよい（中身は同じ）。
>
> **現状:** v0.1 は完成済み。C の最小カーネル + Limine 8.3.2 で QEMU 起動、
> シリアルシェルで Linux / Windows 両対応コマンドが動くことをローカルで検証済み
> （`make test` 48 checks PASS、`make boot-test` BOOT TEST PASSED、ISO 3.8 MB）。
> この仕様書は、その v0.1 から v1.0 へ育てるための全リストである。

## 1. 製品版 v1.0 の判定基準（これが全部できたら製品版）

| 観点 | 判定基準 |
|---|---|
| 起動 | 電源を入れて 30 秒以内にログイン画面、ログイン後 10 秒以内にデスクトップが使える |
| 日常利用 | ブラウザ、メール、文書作成、表計算、写真・動画再生、ファイル管理が追加ソフトなしでできる |
| 安定性 | 1 日 8 時間の連続利用でクラッシュしない。アプリが落ちても OS 全体は落ちない |
| 互換性 | 主要な USB 機器、Wi-Fi、Bluetooth、プリンター、外部モニターが挿すだけで動く |
| カスタム | テーマ・レイアウト・ショートカットを GUI だけで変えられ、元に戻せる |
| セキュリティ | 暗号化、権限管理、署名付き更新が既定でオン。初心者が何もしなくても守られる |
| 更新 | セキュリティ更新が自動で届き、再起動が必要な場合も日時を選べる |
| サポート | 日本語のヘルプ、設定内検索、トラブル時の復旧モードがある |

## 2. 機能一覧

### 2.1 デスクトップと UI（Windows 11 風）

- Windows 11 風デスクトップ：中央寄せタスクバー、スタートメニュー、システムトレイ、通知センター、クイック設定、ウィジェットボード
- スタート：ピン留めアプリ、検索、最近使ったファイル、おすすめ、フォルダー
- タスクバー：位置（下・上・左・右）、大きさ、アイコンの中央／左寄せ、時計・カレンダー、音量・Wi-Fi・バッテリー
- ウィンドウ管理：スナップレイアウト（左右・上下・4 分割）、スナップグループ、タスクビュー、仮想デスクトップ（作成・名前変更・壁紙ごとに変更）
- Mac 風機能：Dock（位置・大きさ・拡大表示・自動で隠す）、Spotlight 風検索（アプリ・ファイル・設定・計算・Web を横断検索）、Mission Control 風一覧（全ウィンドウとデスクトップを一画面で表示）、Launchpad 風アプリ一覧
- 通知：アプリごとの通知オン／オフ、おやすみモード、通知履歴
- ロック画面・ログイン：壁紙、時計、PIN・パスワード・指紋・顔認証（対応機器）、複数ユーザー切り替え
- ダーク／ライトモード、アクセントカラー、透明効果（アクリル／マイカ風）、角丸、影、アニメーションのオン／オフ
- マルチモニター：モニターごとの壁紙・タスクバー、解像度・拡大率・配置の記憶
- タッチ・ペン・ジェスチャー対応（対応機器）

### 2.2 ファイルとストレージ

- ファイルマネージャー：フォルダー、検索、プレビュー、タブ、分割表示、並べ替え、タグ、クイックアクセス、お気に入り
- ストレージ：内蔵・USB・外付け HDD/SSD、SD カード、ネットワークドライブ、クラウド連携
- 検索：ファイル名・中身・種類・日付での検索、インデックスによる高速検索
- 圧縮・解凍（zip など）、ごみ箱（復元・完全削除）、ファイル履歴・バックアップ
- ディスク管理：空き容量表示、クリーンアップ、ディスク暗号化の状態表示

### 2.3 標準アプリ（最初から入っているもの）

- Web ブラウザ（タブ、ブックマーク、拡張機能、プライベートモード）
- メール、カレンダー、連絡先、メモ、時計・タイマー・ストップウォッチ
- 文書・表計算・プレゼン（Office 互換ファイルを開けること）
- 写真（表示・整理・簡単な編集）、動画プレイヤー、音楽プレイヤー、カメラ、ボイスレコーダー
- 電卓、ペイント風お絵描き、テキストエディター
- 設定、ヘルプ、フィードバック
- ストア（アプリの検索・インストール・更新・レビュー）

### 2.4 シェルとコマンド（Linux & Windows 両対応）

- ターミナル：タブ、分割画面、テーマ、フォント、コピー＆ペースト、履歴、補完
- Linux 風コマンド：`ls` `cat` `pwd` `cd` `cp` `mv` `rm` `mkdir` `grep` `ps` `top` `chmod` `ssh` `curl` など
- Windows 風コマンド：`dir` `type` `cls` `copy` `move` `del` `md` `tasklist` `ipconfig` など、同じ意味のコマンドは両方の名前で動く
- シェルスクリプト（Linux 風と Windows 風の両方の基本文法）、環境変数、エイリアス
- パッケージマネージャー（例：`prism install <アプリ名>`）：アプリの検索・導入・更新・削除、依存関係の解決

### 2.5 設定とカスタマイズ（どこでもカスタムできる）

**初心者向け（GUI だけで完結）**

- 初回セットアップウィザード：3 つの質問で「Windows 風／Mac 風／シンプル」を選ぶだけ
- ワンクリック・プリセット：「シンプル」「仕事用」「かわいい」「ダーク」「明るい」など
- モード分けはしない。かんたんモード／上級モードの切り替えはなし。1 つの本格的な Windows レベルの UI で、既定値が分かりやすく、すべての設定が同じ設定画面から段階的に掘り下げられる（よく使う設定が上に、細かい設定が下に）。初心者でも迷わず、上級者も同じ画面で全部変えられる
- 変更はプレビューで確認してから適用、いつでも「元に戻す」「初期状態に戻す」
- 設定内検索：「壁紙を変えたい」と言葉で探せる

**変えられるもの（全リスト）**

- テーマ：色、アクセントカラー、壁紙（写真・動画・スライドショー）、フォント、アイコン、音、カーソル、アニメーション、透明度、角丸、影
- デスクトップ：アイコンの配置・大きさ、ウィジェット、仮想デスクトップの数と名前
- タスクバー／Dock：位置、大きさ、表示するアイコン、自動で隠す、時計の表示形式
- スタート：ピンの並び、表示するフォルダー、検索の対象
- ロック画面・ログイン画面・起動画面
- キーボードショートカット、マウス・タッチパッドのジェスチャー、右クリックメニュー
- アプリごとのテーマ、言語、通知、権限
- シェルの見た目（プロンプト、色、フォント）、ターミナルのテーマ

**上級者向け**

- 設定はすべて `config/theme.toml` などのテキストファイルでも変えられる（GUI と同じ内容）
- テーマファイルの保存・共有・インポート／エクスポート
- プラグイン／拡張機能：デスクトップの部品や機能を追加できる仕組み、公式ストアでの配布と署名チェック
- 自動化：起動時に開くアプリ、定型操作の記録と実行

**壊れないためのルール**

- カスタムで OS が起動しなくなっても、復旧モードから初期テーマに戻せる
- 設定変更は 1 つずつ保存され、失敗した変更だけ巻き戻せる

### 2.6 ネットワークと接続

- Wi-Fi（WPA2/WPA3）、有線 LAN、Bluetooth、モバイル回線（対応機器）
- VPN、プロキシ、ファイアウォール設定
- ファイル共有（LAN 内）、プリンター共有、近くのデバイスとの共有
- ネットワークの診断（接続できないときに原因を表示して直す手順を出す）

### 2.7 マルチメディアとデバイス

- 音声：スピーカー、ヘッドホン、Bluetooth オーディオ、マイク、音量ミキサー
- 画像・動画：主要な形式の再生（mp4、mp3、png、jpg など）、画面キャプチャ、画面録画
- カメラ・マイク：アプリごとの許可、利用中の表示ランプ
- プリンター・スキャナー：自動検出、ドライバーの自動導入
- USB・外部機器：挿すだけで認識、取り外しの安全な手順

### 2.8 アクセシビリティ（誰でも使える）

- 文字の大きさ、コントラスト、色覚サポート、画面拡大、スクリーンリーダー
- 音声入力、キーボードだけで操作できること、スティッキーキー、音声読み上げ
- 日本語・英語をはじめとする多言語表示と入力（IME）

### 2.9 開発者向け

- ターミナル、パッケージマネージャー、Git、主要なプログラミング言語の実行環境
- 仮想化・コンテナの基本対応、WSL 風の Linux 環境（目標）
- ログと診断ツール、クラッシュレポート（送信するかどうかはユーザーが選ぶ）

## 3. 必要な構成

### 3.1 ハードウェア要件（v1.0 の目標）

| 項目 | 最低 | 推奨 |
|---|---|---|
| CPU | 64 ビット、2 コア、1 GHz | 4 コア以上 |
| メモリ | 4 GB | 8 GB 以上 |
| ストレージ | 32 GB（SSD 推奨） | 64 GB 以上の SSD |
| グラフィックス | 1280×720、DirectX 相当 | 1920×1080 以上、GPU アクセラレーション |
| ネットワーク | 有線または Wi-Fi | Wi-Fi 6 |
| ブート | UEFI（BIOS 互換も維持） | UEFI + Secure Boot |

### 3.2 ソフトウェア構成（層で考える）

```

│ アプリ層：ブラウザ、メール、文書、設定、ストア      │
├────────────────────────────────────────────┤
│ デスクトップ環境：ウィンドウ管理、タスクバー、        │
│   Dock、Spotlight風検索、テーマエンジン、通知        │
├────────────────────────────────────────────┤
│ システムサービス：ログイン、権限、更新、バックアップ、 │
│   プリンター、ネットワーク、オーディオ、電源管理      │
├────────────────────────────────────────────┤
│ ライブラリ・ランタイム：グラフィックス、フォント、     │
```

### 3.3 各層の中身

- **ブート：** UEFI 対応、Limine（v0.1 で採用）からの発展、セキュアブート、ディスク暗号化の解除、復旧モードへの入口、起動ログ
- **カーネル：** プロセスとスレッド、スケジューラー、仮想メモリ、割り込み、システムコール、デバイスドライバー（ストレージ、USB、グラフィックス、ネットワーク、音声、入力）
- **ファイルシステム：** 起動用・ユーザー用・システム用の分離、ジャーナル、権限、暗号化、スナップショット／復元ポイント
- **グラフィックス：** フレームバッファ（v0.1 で寸法取得済み）→ GPU アクセラレーション、ウィンドウの合成（コンポジター）、フォント描画、HiDPI
- **サウンド：** ミキサー、デバイス切り替え、アプリごとの音量
- **ネットワーク：** TCP/IP、DNS、DHCP、Wi-Fi、Bluetooth、VPN、ファイアウォール
- **システムサービス：** ユーザー管理、ログイン、権限、電源管理（スリープ・休止・バッテリー）、時計、言語、更新、バックアップ、診断
- **パッケージと更新：** アプリと OS の署名付きパッケージ、差分更新、ロールバック（更新に失敗したら前の版に戻る）、更新の日時指定
- **インストーラー：** USB からのインストール、言語・キーボード・ユーザー・暗号化の選択、既存 OS とのデュアルブート、インストール後の初回セットアップ

## 4. セキュリティ（しっかり、が具体的に何か）

### 4.1 起動とディスク

- セキュアブート：署名されたブートローダーとカーネルだけ起動する
- ディスク暗号化：既定でオン（ユーザーがオフにできるが、警告を出す）。パスワードを忘れた場合の回復キーの案内
- 検証済みブート：システムファイルが改ざんされていたら起動を止めるか警告する
- 復旧モード：暗号化解除、起動修復、初期化（データを残す／消すを選べる）

### 4.2 アカウントと権限

- 複数ユーザー、ゲストユーザー、保護者による制限（子供用アカウント）
- 管理者と一般ユーザーの分離。管理者権限が必要な操作はその場で確認する
- アプリごとの権限：ファイル、カメラ、マイク、位置情報、ネットワーク、通知、クリップボード。許可は後からいつでも変えられる
- パスワード、PIN、生体認証、2 段階認証（対応サービス）

### 4.3 アプリの隔離

- アプリはサンドボックスで動く。1 つのアプリが落ちても、他のアプリや OS には影響しない
- アプリは自分のフォルダー以外を勝手に読めない。必要なときだけ許可を求める
- ストアのアプリは署名チェックと審査を通す。外部から入れたアプリは警告を出して、実行するかどうかユーザーが決める

### 4.4 ネットワークとプライバシー

- ファイアウォール：既定でオン。アプリの通信は許可リストで管理
- 暗号化通信（HTTPS）を優先し、安全でない接続は警告する
- 位置情報・診断データ・利用データの収集は既定で最小限。送るかどうかは設定で選べる。何を送っているか設定画面で見られる
- トラッキング防止、広告識別子の管理

### 4.5 マルウェア対策と更新

- マルウェア検査：ダウンロードしたファイルとアプリの検査、定義ファイルの自動更新
- 署名付き更新：OS とアプリの更新は署名を確認してから入れる。署名が合わなければ入れない
- セキュリティ更新は自動で届く。緊急の更新はすぐに、通常の更新はユーザーの選んだ時間に
- 更新に失敗したら自動で前の版に戻る（ロールバック）
- 脆弱性の報告窓口と、修正までの手順を決めておく

### 4.6 監査と復旧

- 監査ログ：ログイン、権限の変更、アプリのインストールを記録（ユーザーが見られる）
- バックアップ：ファイル履歴、システムの復元ポイント、クラウドへのバックアップ（任意）
- 紛失・盗難時：デバイスの暗号化と、遠隔ロック／消去（対応する場合）
- パスワードを忘れた場合の回復手順（回復キー、管理者によるリセット）

### 4.7 ビルドと配布のセキュリティ（GitHub Actions）

- 依存関係の固定（バージョンを決め打ちする）、脆弱性スキャン（Dependabot 風）
- ビルドはクリーンな環境で、再現可能ビルドを目指す
- リリースは署名付きで、チェックサムを公開する
- シークレット（鍵・トークン）はリポジトリに入れない。GitHub の Secrets を使う
- プルリクエストはレビューと CI（ビルド＋テスト＋セキュリティ検査）が通ってから取り込む

## 5. その他

### 5.1 パフォーマンス目標

- 起動 30 秒以内、ログイン後 10 秒以内に操作可能
- アプリの起動：ブラウザ 3 秒以内、ファイルマネージャー 1 秒以内を目安
- アイドル時のメモリ使用量を抑え、バッテリー駆動で 8 時間の通常利用を目安
- 100 個のウィンドウを開いても操作が重くならないこと

### 5.2 互換性

- 主要なファイル形式（文書、表計算、画像、動画、音声、圧縮）を開ける
- USB、Wi-Fi、Bluetooth、プリンター、外部モニターの主要機器に対応
- Linux アプリの実行（目標）、Windows アプリの実行は v1.0 の必須ではない（将来の検討事項として明記する）

### 5.3 テストと品質（GitHub Actions で回すもの）

- ユニットテスト：シェル、ファイル操作、テーマ読み込みなど（v0.1 で 48 checks PASS の土台あり）
- ビルドテスト：カーネルと ISO が毎回作れること
- 起動テスト：QEMU で起動し、バナーとシェルが出ること（v0.1 で PASS）
- UI テスト：デスクトップ、ウィンドウ、設定の基本操作
- セキュリティ検査：依存関係の脆弱性、静的解析、シークレットの混入チェック
- パフォーマンステスト：起動時間、メモリ使用量の計測
- リリースチェック：ISO の作成、チェックサム、署名、インストールテスト

### 5.4 ドキュメントとサポート

- ユーザー向けヘルプ（日本語）：初回セットアップ、基本操作、カスタム方法、困ったときの手順
- 開発者向けドキュメント：アーキテクチャ、ビルド方法、コントリビューションの手順
- リリースノート、既知の問題と回避策、FAQ

### 5.5 ライセンスと配布

- ライセンス：MIT（v0.1 で採用済み）
- 配布：GitHub Releases から ISO を配布、チェックサムと署名を公開
- プライバシーポリシーと利用規約（製品版までに用意する）
