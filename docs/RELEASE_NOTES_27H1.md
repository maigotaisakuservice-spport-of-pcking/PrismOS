# PrismOS 27H1 リリースノート

製品版「27H1」のリリースノートです。できたことと、できていない・
まだ検証できていないことを分けて正直に書きます。
配布は GitHub Releases からのみ行います。

- 版数表記: 製品版から年・半期表記（27H1）を使います。OS 内の
  表示（バナー、`ver`、設定の更新ページなど）はすべて 27H1 です。
  更新マニフェストとの新旧比較には内部の数値系列
  （PRISM_VERSION_ORDER）を別に持ち、表示ラベルとは分けてあります
  （`kernel/version.h` 参照）。

## 既知の問題・未検証（正直な一覧）

未実装:

- **PDF の日本語出力**: PDF はテキスト抽出と最小生成までで、
  日本語の出力は '?' になります（ラテン文字のみ）。
- **音声読み上げ（TTS）**: アクセシビリティは字幕表示までで、
  音声合成はありません。

実装済みだが未検証:

- **カメラの実転送**: UVC ドライバ（記述子解析・プローブ/
  コミット・フレーム組立）は実装し、ホストテストと xHCI
  列挙で確認済みですが、QEMU メインラインに UVC エミュ
  レーションがないため、実デバイスからの映像転送は
  未検証です。
- **音声録音の採取完了**: 録音ドライバは実装しましたが、
  QEMU の音声バックエンドがゲストの採取 DMA を進めないため、
  採取完了を現環境で観測できていません。2026-11-24 に
  audiodev none と SDL ダミーの両方で実測し、どちらも
  LPIB が 0 のまま 0 バイトで正直に失敗することを確認
  しました。採取ロジックそのもの（BDL 構築・目標バイト数・
  DMA 位置からの取得量・ピーク走査）はホストテスト
  test_hda_cap（54 件）で同じコードを検証済みで、ADC 設定
  から DMA 設定・LPIB ポーリングまでの到達点も
  hda-record-test で確認済みです。実サンプルが届くところ
  までは実キャプチャバックエンドか実機が必要です。
- **マルチモニタ**: ミラー表示を実装しましたが、QEMU が
  フレームバッファを 1 つしか報告しないため検証できていません。
- **Wi-Fi／Bluetooth**: 仕様レベルの記述のみで、ドライバは
  実機確認待ちです。
- **指紋・顔認証**: テンプレート照合とロック解除の流れは
  テストデータで検証済みですが、実センサーでの捕捉は
  未検証です。
- **実機ブート**: 実機（物理 PC）での起動確認は未実施です。
  検証は QEMU（KVM なしのソフトウェアエミュレーション）と
  GitHub Actions を前提にしています。
- **初心者の使いやすさ実測**: 初回セットアップの所要時間を
  初心者で実測する検証は未実施です（自動操作での計測のみ）。
- **デスクトップウィジェットの実フィード**: 天気・ニュース
  ウィジェットの配信の取得・表示はローカルのテストサーバー
  で確認済み。実際の外部サービスの配信での動作は未検証
  です。

既知の不具合・制約:

- **driver-test が現環境で不合格**: ドライバテスト
  （AHCI／virtio-blk／USB）を仕上げ段階で 3 回実行し、
  3 回とも virtio-blk 編の「ファイル書込後のプロンプト待ち
  （20 秒）」で失敗しました。待ち時間を延ばした手動再現では
  約 26 秒でプロンプトが戻り、シェル生存とデータの正常を
  確認しています。ハングや破損ではなく、KVM のない
  ソフトウェアエミュレーション下での極端な低速が原因と
  判断していますが、テスト自体は不合格のまま記録します
  （タイムアウトを延ばして合格にはしていません）。
  AHCI 編と書込自体は毎回合格しています。
- **F8 は意図的に未修正**: アカウント保存（users.c）の固定 IV と
  64 ビット照合値は、最終深層チェックで指摘されましたが、
  ユーザーごとのソルト付き KDF で鍵が分離されており実害の
  経路がないこと、形式変更で既存ユーザーを締め出す危険が
  あることから、今回は意図的に直していません（将来の形式
  移行時に扱います。詳細は最終深層チェック報告書）。
- **互換レイヤーの範囲**: 動くのは PrismOS の呼び出し規約に
  合わせた ELF ゲストプログラムと、PE (exe) のコンソール系
  サブセット（KERNEL32 60 API）、Mach-O 64-bit 実行ファイル
  と .app バンドル内の実行ファイルまでです（.dmg は実行形式
  ではないため対象外）。既存の他 OS 向けアプリがそのまま
  動くわけではありません（本格対応は 27H2 の計画です）。
- **ブラウザの JavaScript**: 整数演算中心のサブセット
  解釈器です（配列・オブジェクト・DOM は対象外）。
- **スクリーンショットの保存形式**: OS 内蔵のスクリーン
  ショットは原寸（1280×800・24 ビット BMP、3072054 バイト）
  で保存されます（diskfs 版 5 の大きなファイル領域を使用）。
- **チェックリスト項目 3・5**: 実機（Wi-Fi／Bluetooth／
  プリンター／外部モニター）と初心者実測は、性質上この
  環境では検証できないため、未検証のまま残ります。

## 次の大型アップデート（27H2）の予告

27H2 の目玉は Win32 互換の本格化です。段階は
(1) PE ローダ、(2) コンソール系 API サブセット、
(3) GUI アプリ対応、(4) 対応範囲の拡大とし、
到達できた対応範囲は正直に報告します。
製品版完成後にはペネトレーションテストを実施し、
セキュリティの定期チェック（日次監査・毎時 0-day 確認）を
再開します。
