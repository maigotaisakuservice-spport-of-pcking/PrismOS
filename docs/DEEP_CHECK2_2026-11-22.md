## A. 国際化・言語

### A-1言語切替がデスクトップGUIにほぼ届いていない
- 根拠：`kernel/desktop.c` の文字列リテラルは実測472件、そのうち日本語を含むものは **0件**。言語設定（`desk_settings.language`）が `desktop.c` 内で効くのは設定画面の表示行（:947）と切替時の通知（:6133-6138）のみで、その通知文自体が英語（`"Language: Japanese"`）。
- 切り替わるのはシェルの `help`（`shell/core.c:306-` に言語分岐あり）と初回インストール時の言語質問（`kernel/shell.c:3840-3886`）だけ。タスクバー・Dock・ランチャー・全16アプリ・ダイアログは、日本語設定でも全て英語表示。
- `kernel/settings.h:83-85` のコメントは「ヘルプと主要な画面表示が切り替わる」と書くが、画面表示は実際には切り替わらない。仕様の「発売時対応言語は日本語と英語」「初回セットアップで言語選択」に対し、選択の結果がGUIに反映されない状態。
- 注：ANGLE_CHECK は「切替の仕組み自体が存在しない」と報告したが、その後仕組みは実装された。本件はその実装の到達範囲（GUIカバー率ほぼ0）という新規の精密化。

### A-2キーボード配列は US / JIS の2種のみ
- 根拠：`kernel/settings.h:86-87`（`kbd_layout` は 0=US、1=JIS の二値）。英・独・仏等の配列はなく、設定も二値トグル（`kernel/desktop.c` の設定画面 `j` キー）のみ。

### A-3日付・時刻の表示書式に選択肢がない
- 根拠：タスクバー時計は `clock_text` の5文字＝HH:MM のみ（`kernel/desktop.c:4200-4204`）。秒・日付は表示されず、12時間表示や地域書式（年/月/日の順序等）を選ぶ設定項目自体が `kernel/settings.h` の設定構造体に存在しない。

## B. 時刻基盤

### B-1時計を合わせる手段が一切ない（NTPなし・手動設定なし・タイムゾーンなし）
- 根拠：ネットワークスタックに NTP 実装なし（`kernel/netstack.c` 等に該当コードなし）。RTC への書き込み関数自体が存在しない（`rtc_set`/`rtc_write`/`cmos_write` の検索0件）。`date`/`time` に相当するシェルコマンドもない。タイムゾーン・夏時間の概念もツリー全体で0件。
- 影響：表示時刻・カレンダー・監査ログの時刻・メールの日付は全て RTC の生値に依存し、ずれても OS 内からは直せない。

## C. メールの深さ

### C-1MIME が丸ごと無い（符号化なし・復号なし・Dateヘッダが空）
- 根拠：base64 / quoted-printable / Content-Type / encoded-word の実装がツリー全体（kernel・shell・compat・drivers）で **0件**。
- 送信側：ヘッダは From / To / Subject / Date のみ（`shell/mail.c:300-331`）。しかも **Date ヘッダは値が空**（`shell/mail.c:325-330` は `"Date: "` の直後に改行）。日本語の件名・本文は MIME 宣言なしの生 UTF-8 で送られ、受け手の環境で文字化けしうる（RFC の符号化規則にも反する）。
- 受信側：世間の標準形式（base64 本文、encoded-word 件名、ISO-2022-JP 本文）を復号できないため、エンコードされた文字列がそのまま表示される。ローカルテストサーバ相手では露見しない相互運用性の欠落。
- 注：添付ファイル自体は追加スコープ第2弾にあるが、MIME 符号化/復号という土台はスコープ文に含まれていない。

### C-2メールに返信・転送・検索・署名・フィルタがなく、アカウントも1つだけ
- 根拠：Mail 画面の操作は「移動・Enterで読む・c で新規作成・r で受信・d で削除」が全て（`kernel/desktop.c:4026` のフッタ）。返信（引用・宛先/件名の自動設定）・転送・本文/件名検索・署名の自動付与・振り分けルールの実装なし。設定構造体も smtp/pop3/imap 各1組＋ユーザ1つだけ（`shell/mail.h:43-59`）で、複数アカウントを持てない。

## D. アプリの機能の深さ

### D-1全エディタに Undo/Redo と検索・置換がない
- 根拠：`undo`/`redo` の検索は無関係な1件（ドライバ再有効化の説明文）のみ。Notes / Docs / Slides / Sheet / メール作成のいずれにも、操作の取り消し・やり直し、文字列の検索・置換の実装がない（`kernel/desktop.c` 内に find/replace 相当の処理なし）。誤って消した文字は戻せない。

### D-2Photos は表示のみ（編集・スライドショー・ズームなし）
- 根拠：`draw_photos`（`kernel/desktop.c:2004-`）とキー案内は一覧・移動・開くのみ。回転・トリミング・明るさ調整等の編集、スライドショー再生、拡大表示の実装なし。対応形式が BMP のみである点は既報だが、編集機能の欠落は未報告。

### D-3Sheet にグラフ・並べ替え・複数シート・範囲コピー/フィルがない
- 根拠：`shell/sheet.c` に chart/sort/fill/copy 相当の実装なし。関数4種・寸法・保存形式の上限は既報だが、表計算の周辺機能（グラフ化、行の並べ替え、シートの複数枚管理、範囲の複写）は未報告。なおセル参照つき計算式（=A1+B2、範囲指定）は動作する（下記「問題なし」参照）。

### D-4Files の操作が薄く、基盤にも日付情報がない
- 根拠：Files の操作は一覧・開く・削除のみ（`kernel/desktop.c:681` のフッタ）。右クリックメニューも Open / Copy name / Delete の3項目だけ（同:4813-4819）。GUI からの新規作成・名前変更・並べ替え・サイズ表示がない。さらに基盤側の制約としてファイルにタイムスタンプが存在しない（E-2）ため、日付表示や日付順ソートは構造的に不可能。

### D-5ブラウザの残り（追加スコープ第1弾の範囲外の分）
- 根拠：Cookie の実装が HTTP スタック全体で0件（検索ヒットは virtio の無関係な変数名のみ）。ページ内検索なし、取得したページをファイルへ保存する経路なし、表示ズームなし。リンク・画像・CSS/JS・HTTPS は追加スコープ第1弾にあるが、この4点は含まれていない。Cookie がないため、ログインが必要なサイトは原理的に使えない。

## E. 入出力・データ形式

### E-1文字コードは UTF-8 のみ（Shift_JIS 等の変換なし）
- 根拠：Shift_JIS / EUC-JP / ISO-2022-JP / UTF-16 の変換コードがツリー全体で0件（`charset` の言及自体も0件）。フォントの問題ではなく、復号の仕組み自体がない。日本語環境で流通する旧来のテキストファイル（Shift_JIS）や ISO-2022-JP のメールは文字化けして読めない。

### E-2ファイルにタイムスタンプが記録されない
- 根拠：永続層のエントリは `name / size / start_sector / iv` のみ（`shell/diskfs.h:66-76` 付近）、RAM 側も `name / data / size / used` のみ（`shell/vfs.c:23-28`）。作成日時・更新日時を保存する欄自体がない。影響：日付順の並べ替え、「最近使ったファイル」、バックアップの世代判断、監査との時刻つき突き合わせができない。

### E-3PDF の読み書きが一切ない
- 根拠：`pdf` への言及がツリー全体で実質0件。Docs は.docx と自形式テキストのみで、文書配布の事実上の標準形式である PDF を開くことも書き出すこともできない。

### E-4クリップボードの到達範囲が狭い
- 根拠：テキストのみ・最大1024バイト・1件のみ（`kernel/desktop.c:217-218`、`CLIP_MAX 1024`）。コピー元は Notes の行と Files のファイル名だけ、貼り付け先は Notes だけ（同:4532、:5857）。Docs / Sheet / メール作成 / ターミナル入力へは貼れない。画像やファイル自体のコピー&ペースト、クリップボード履歴もない。

### E-5ファイルのドラッグ&ドロップがない
- 根拠：マウスのドラッグ処理は浮動ウィンドウの移動専用。ファイルをアプリのアイコンやウィンドウへドラッグして開く経路がない（ドロップ処理の実装なし）。

### E-6シェルの字句の深さ（パイプ等とは別の残り）
- 根拠：ワイルドカード展開なし、`;` / `&&` のコマンド連結なし、追記リダイレクト `>>` なし（リダイレクトは `>` のみ、`shell/core.c:373`）、引用符は二重引用符のみでシングルクォートなし（同:141）。パイプ・履歴・環境変数・スクリプトは追加スコープ第2弾にあるが、この4点は含まれていない。

## F. アクセシビリティ・入力調整

### F-1アクセシビリティの具体策が皆無
- 根拠：文字の拡大率はコンパイル時定数 `TEXT_SCALE 2` 固定（`kernel/desktop.c:40`）で、利用者が変える設定項目がない。拡大鏡、ハイコントラストテーマ（テーマは dark/light の2種のみ）、スクリーンリーダ/読み上げ、スティッキーキー、オンスクリーンキーボードは、いずれも実装の検索0件。設定構造体（`kernel/settings.h`）にも該当フィールド自体がない。
- 注：DEEP_CHECK は仕様 §2.8 を「未実装の仕様領域」と一括りに挙げただけで、具体項目の洗い出しは本報告が初めて。

### F-2入力デバイスの調整項目がない
- 根拠：マウス速度、キーリピート間隔・開始遅延、ダブルクリック間隔に相当する設定が `kernel/settings.h` にも `kernel/mouse.c` / `kernel/keyboard.c` の調整コードにも存在しない。

## G. 運用・診断

### G-1クラッシュと起動の記録がディスクに残らない
- 根拠：例外ハンドラはシリアル出力のみ（`kernel/idt.c:87-`）。起動ログや例外記録をファイルに残す仕組みがなく、再起動後に OS の中から障害を振り返る手段（dmesg 相当、boot.log）がない。シリアルがつながっていない利用者は記録自体にアクセスできない。

### G-2GUIターミナルにスクロールバックがない
- 根拠：画面グリッドは表示行数分のみ確保される（`kernel/desktop.c:5116-5120`、確保量は cols×rows ちょうど）。上に流れたシェル出力は GUI では二度と見られない（シリアル側には残る）。長い `help` やエラーの遡及が画面ではできない。

### G-3更新の入手経路はサーバ経由のみ
- 根拠：`update` コマンドの usage は `update server <host> [path]` 前提（`kernel/shell.c:2864`）。USB メモリやローカルファイルからのオフライン更新（署名検証つきファイル適用）の経路がない。

### G-4バックアップの粒度と置き場所
- 根拠：復元ポイント（スナップショット）は同一ディスク内の領域にのみ存在し、それ自体を外部メディアへ書き出す経路がない。復元も全ファイル一括の差し替えのみで、ファイル単位で選んで戻すことはできない（スナップショットの枠数・検証の話は既報。本件は「書き出しと粒度」のみ）。

### G-5ネットワーク設定は DHCP 自動のみ
- 根拠：設定構造体にネット系フィールドがなく、`net` コマンドは状態表示のみ。静的 IP・ゲートウェイ・DNS サーバの手動設定や、端末名（ホスト名）の設定手段がどこにもない。DHCP が使えないネットワークでは接続自体ができない。
