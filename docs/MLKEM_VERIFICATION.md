# ML-KEM 検証結果

PrismOS の耐量子暗号のうち、鍵共有（ML-KEM）の実装が参照実装と一致することを確認した記録。署名（ML-DSA）の本番適用（更新マニフェスト検証、ドライバ署名）とは別に、ML-KEM 単体の検証範囲と、まだ届いていない範囲を正直に線引きする。

- 検証日: 2026-11-25（最終ツリー HEAD d3b465f で再実行）
- 対象実装: `shell/mlkem.c` / `shell/mlkem.h`（ML-KEM-512 / 768 / 1024）
- テスト: `tests/test_pqc.c`（ベクトル: `tests/pq_vectors.h`、`tests/pq_vectors_512.h`）

## 参照実装と照合方法

- ML-KEM-768 / 1024: Python の cryptography ライブラリ（FIPS 203 準拠）の公開ベクトルと照合
- ML-KEM-512: 同ライブラリに無いため、PQClean（pqcrypto）を参照実装として双方向ベクトルで照合。ベクトル生成時に `scripts/pq-kat512.py` が相互検証済み
- 土台の SHA3-256 / SHA3-512 / SHAKE128 / SHAKE256 も同じテストで公開ベクトルと照合（3メッセージ）

## 検証項目と結果

`env -u PYTHONNOUSERSITE make test` の `test_pqc` は **41 checks / 0 failures**（2026-11-25 再実行で確認）。

パラメータセットごとに確認した内容:

| 対象 | 鍵生成 | 復号（既知の暗号文） | 暗号化 | 往復 | 改ざん検出 |
|---|---|---|---|---|---|
| ML-KEM-512 | 一貫性確認 | PQClean ベクトルと一致 | PQClean ベクトルと一致（双方向） | 一致 | 改ざん暗号文で共有秘密が変化 |
| ML-KEM-768 | 公開鍵がベクトルと一致 | ベクトルと一致 | 往復で確認 | 一致 | 改ざん暗号文で共有秘密が変化 |
| ML-KEM-1024 | 公開鍵がベクトルと一致 | ベクトルと一致 | 往復で確認 | 一致 | 改ざん暗号文で共有秘密が変化 |

## 届いている範囲・届いていない範囲

届いている:

- ML-KEM-512 / 768 / 1024 のプリミティブ（鍵生成・カプセル化・脱カプセル化）が参照実装と一致
- シェルの `pq` コマンドから ML-KEM-768 の鍵ペア生成（pqkem.pub / pqkem.key へ保存）、カプセル化、脱カプセル化が使える

届いていない（正直な線引き）:

- **本番の通信プロトコルでの鍵交換には未適用**。仕様の決定どおり ML-KEM は「将来の鍵交換」の位置づけで、現時点でネットワーク越しに KEM 鍵交換を行うプロトコル実装はない
- 本番の検証経路で稼働している耐量子暗号は署名側（ML-DSA：更新マニフェストとドライバ署名の検証）であり、本書の対象外
